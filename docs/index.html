GET STARTED

Four steps to focus.

  1. Download and extract the source repository ZIP.
  2. Open chrome://extensions in Chrome desktop.
  3. Enable Developer mode and choose Load unpacked.
  4. Select the extracted extension/ folder containing manifest.json.

Browser permission prompts are expected for website controls and tracking. Read the permission explanation before installing.

Your focus is yours to shape.

FocusFlow stores core activity data using Chrome extension storage. Optional backend syncing is separate and requires your configuration. Browsing time is an estimate of active browser use, not a measure of attention.
