# Growth launch plan

## Positioning

FocusFlow is a Chrome productivity workspace combining website blocking, browsing activity insights, tasks, Pomodoro sessions and website controls. Avoid unverified claims such as "AI powered", "private by design" certification, store availability or guaranteed results.

## Before sharing

- Check installation and key features in a real clean Chrome profile.
- Replace the existing README hero image only with genuine screenshots.
- Verify licensing and extension release packaging.
- Add GitHub topics and a social-preview image manually in repository settings.
- Publish a landing page only after hosting and its URL are verified.

## Launch copy (draft; update after testing)

**LinkedIn:**

I built FocusFlow, an open-source Chrome productivity extension for reducing distractions and understanding browsing habits. It brings website blocking, focus sessions, tasks and productivity insights together. It's currently installable from source. I'd appreciate feedback on the onboarding and the features you'd actually use.

Repo: https://github.com/cosmiccoder200x-sys/Focusflow

**Short video hook:** "I kept switching tabs instead of studying, so I built a Chrome extension to help me focus." Show the real extension immediately. End with source installation link.

**Community post:** "I built an open-source Chrome focus extension and would love feedback on the installation process. Are the requested permissions explained clearly?" Always follow self-promotion rules.

## Referral tracking

GitHub Insights → Traffic provides referring sites, views and unique visitors for a rolling period. Record weekly snapshots in a private sheet. Avoid putting analytics scripts inside the Chrome extension. If a standalone landing page is hosted later, measure privacy-respectful outbound clicks to GitHub without collecting browsing activity.

## Suggested experiments

- Week 1: update About description, topics, README, license, and installation.
- Week 2: test package and capture real visuals.
- Week 3: publish one useful short video and one engineering write-up.
- Week 4: evaluate referring sources, install friction, stars and substantive feedback; improve the weakest step.

Use quality feedback and successful installations as primary success signals, not vanity stars.
